# Fuelio mobile feature audit and Motorledger Android coverage

Reviewed November 25, 2026. This inventory covers the vendor's published module guides and listings for both mobile platforms. Store releases, country coverage, subscriptions and hardware affect availability. It is a documentation audit, with no hands-on inspection of either paid Fuelio app.

## Using the APK

Copy **Motorledger-1.0.0.apk** to an Android phone running Android 9 or later with an up-to-date Android System WebView. Open the APK, allow the file manager to install it if Android asks, and tap **Install**. The app opens with a clearly labeled sample vehicle. Use **More → Garage → Add vehicle** to begin your own log.

For GPS, select the intended vehicle, open **Trips**, and tap **Start GPS trip** before driving. Grant precise location and, where prompted, notification permission. Finish from the notification or the Trips screen, then review and save the recording. GPS availability and battery-management behavior vary by handset. The APK bundles its screens and assets and declares no Internet permission.

For manual web transfer, use **More → Data & backups → Download backup** on the source and **Restore backup** on the destination. GPS trip mileage transfers with its vehicle. The Android app provides the route preview and GPX export.

## Build

### Release verification

Android Build Tools verified the APK v3 signature and ZIP alignment. The manifest identifies package `app.motorledger.garage`, version `1.0.0`, minimum API 28 and target API 35. The package is 578,892 bytes. Its SHA-256 digest is `3ebb3fd5a415a8d655cdea69a7d3bd0c6b358fed328bbbb2925b2df3519478ff`.

Tests loaded the actual assets extracted from the signed APK at phone width in Chromium. They exercised bottom navigation, fill-up persistence after reload, a simulated GPS recording through journal save and GPX export, backup restore, calendar handoff data and print report generation. The native bridges in this test were simulated. No Android phone was attached, and the available software-emulation configurations failed to boot on this Windows host. Installation, system picker behavior and screen-locked GPS recording on a handset remain unverified.

The included PowerShell 7 build script consumes JDK 17, Android SDK Platform 35 and Build Tools 35.0.0. Set `JAVA_HOME` and `ANDROID_HOME`, then run `./build.ps1` from this directory. The script links Android resources, compiles Java and DEX, aligns the APK, signs it and verifies its signature. It keeps the update-signing key outside the project under the current Windows user's local app data. Future in-place updates require the same signing identity and a higher version code.
